# Exercise 1: the prompts

The four prompts for [exercise 1](exercises/01-agent-basics), as on the slides. Open this
file in your browser or an editor, not in Claude Code, so the agent doesn't read ahead.

Start Claude Code in `exercises/01-agent-basics`, then paste each prompt as is, one step at
a time.

## Step 1 of 4: Explore the code

```text
Explore this repository and explain what the application does. Identify the main components and how to run its tests. Do not modify anything.
```

## Step 2 of 4: Investigate the bug

```text
There is a bug in the late-payment fee calculation. Find it and explain the root cause. Do not modify the code yet.
```

## Step 3 of 4: Fix it, and prove it

```text
Fix the bug. Add a unit test that reproduces the problem and run the tests to verify the fix.
```

## Step 4 of 4: Review the change

```text
Show me what you changed, explain why, and identify any remaining risks.
```
